# Instruções para o Claude

## Notificações no celular

O usuário acompanha as sessões pelo celular e não tem como saber que precisa agir se não for notificado.
Use a ferramenta `PushNotification` (carregue via ToolSearch se necessário) sempre que:

- for fazer uma pergunta ou precisar de uma decisão do usuário — notifique **antes** de perguntar;
- estiver bloqueado e não puder continuar sem o usuário;
- terminar uma tarefa longa (render, build, instalação, etc.).

Mensagem curta, em português, começando pelo que o usuário precisa fazer.
Ex.: "Preciso da sua decisão: qual trilha usar no reel?"
